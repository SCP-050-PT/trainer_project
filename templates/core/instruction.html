1. Добавить класс

Меню → «Классы» → кнопка «Добавить класс». Укажите параллель и литеру.

2. Импорт учеников

В таблице классов нажмите иконку загрузки рядом с классом. Загрузите Excel/CSV с колонкой ФИО. Система выдаст PIN-коды.

3. Посмотреть PIN

Меню → «Ученики». Можно искать по ФИО, фильтровать по классу и экспортировать в CSV.

4. Создать тест

Меню → «Экзамены» → «Редактор тестов». Откроется ограниченная админка, где можно создавать тесты и вопросы.

5. Назначить тест

Меню → «Экзамены» → «Назначить тест». Выберите тест, класс и дедлайн. Ученики увидят его в кабинете.

6. Статистика

В разделе «Экзамены» нажмите «Статистика» у назначения. На «Обзоре» есть график активности и экспорт отчёта.

7. Профиль

Меню → «Профиль». Можно изменить имя, фамилию, предмет и пароль.
